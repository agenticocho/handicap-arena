# ARCADE CONCEPT VARIANTS — labelled, with stated weight

Grant: Mike, 2026-10-14 (artistic freedom to explore a few concepts; compute is free).

Rules that still bind (none are style rules):
1. Sort on the aggregate; belt is a label, never sort key.
2. A scratched entrant is NO MEASUREMENT, never zero.
3. `card_version` is a hard partition and is not the release version.
4. Truncation is not a wrong answer; placement is not comparable.
5. Every number must name its scorer (parser, execution, or ground truth) — never a model.

Settled frame (not open): entry is a cabinet wall in attract mode · selection is direct ·
no avatar · the engine is a character grid ("an engine is not specifiable; a grid is").

What is open, and varied here: what a cabinet looks like · how the detail panel reads ·
how a trace plays · how the field leaderboard sits inside the arcade · how much chrome.

Each variant is single-file HTML, self-contained (no external resources, no CDN, no images).

| label | file | engine | weight (bytes) | load needs | character |
|---|---|---|---|---|---|
| **A** | `arcade_concept_a_minimal.html` | DOM + text | 10,188 | nothing | phosphor palette, high-score table entry, no audio, no canvas, no scanlines; smallest possible screen |
| **B** | `arcade_concept_b_canvas.html` | Canvas 2D 320x240 + cabinet | 22,107 | nothing | modernized 8-bit tile cabinet: 24px tiles, beveled walls, slide tween, CRT scanlines/vignette, three-channel WebAudio, shake on blocked moves |
| **C** | `arcade_wall.html` | DOM (attract wall) | 204,707 | generated data only | the field leaderboard inside the arcade: cabinets as wall cards, direct selection, four Ocho clauses by construction; heaviest because it carries every graded entrant |

Notes on weight honesty:
- Weight is measured with `wc -c` on the generated file, not estimated.
- Variant A is the floor: drop audio, drop canvas, drop chrome; only what is on screen.
- Variant C is heavy because the data is inlined; it is the whole field, not a preview. A generated
  subset would be smaller but would stop being reproducible from the bundles.
- Catalogued cabinets nobody has run do not appear in any variant (status stays NEVER RUN).
